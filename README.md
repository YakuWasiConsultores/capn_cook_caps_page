# 🧢 CAP'N COOK® // KRYSTAL CAPS

> **Headwear Lab & Streetwear Parody // Breaking Bad & mySHOUT.US Replica**

Plataforma interactiva inspirada en la estética retro de *Breaking Bad* y *mySHOUT.US* para la personalización y exhibición de gorras urbanas de alta calidad.

---

## 🧪 Características Principales

- **The Cook Lab (Personalizador Interactivo):**
  - Selección de modelo de gorra (*Fitted 59FIFTY*, *Snapback 9FORTY*, *Trucker*, etc.).
  - Configuración en tiempo real de parches conmemorativos (World Series, All-Star, Ediciones Especiales).
  - Pines metálicos, cordones reflectivos, costuras y stickers UV intercambiables.
  - Vistas frontal y de perfil dinámicas.
- **El Barril (Carrito de Compras Temático):**
  - Cálculo de pureza y total.
  - Generación automática de orden de pedido vía WhatsApp lista para despacho.
- **mySHOUT.US Retro Experience:**
  - Contestador de voz interactivo de Jesse Pinkman.
  - Efectos de sonido y diseño retro 2000s.
- **Catálogo de Lotes Oficiales:**
  - Fichas técnicas detalladas por lote de producción.

## 💻 Despliegue Local o en GitHub Pages

Para visualizar la web localmente:
1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` directamente en tu navegador o levanta un servidor estático local (por ejemplo `npx serve` o la extensión *Live Server* en VS Code).

Compatible 100% con **GitHub Pages** como sitio estático sin requerir backend.
